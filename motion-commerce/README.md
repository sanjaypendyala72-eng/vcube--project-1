# NOVA — Motion Commerce

React + Vite e-commerce frontend with a centralized motion language.

## Run
npm install
npm run dev

## Included
- Responsive React storefront
- Home, shop, product detail, wishlist, cart, checkout
- Search/filter/sort
- localStorage cart and wishlist
- Motion tokens and reduced-motion support
- Accessible semantic controls
- Performance-conscious transforms/opacity
- Mock product data ready for API integration

This is a frontend demo. Connect authentication, inventory, order creation and payment processing to a secure backend before production.
